# 🌦️ Weather Dashboard

A responsive Weather Dashboard built using **HTML, CSS, and JavaScript** that allows users to search for a city and view its current weather information using the OpenWeatherMap API.

## 🔗 Live Demo

**Live Website:** [Weather Dashboard](https://juhiparwa-1507.github.io/weather-dashboard/)

**GitHub Repository:** [weather-dashboard](https://github.com/juhiparwa-1507/weather-dashboard)

## 📌 Project Overview

The Weather Dashboard provides a simple and user-friendly interface for checking current weather conditions in different cities. Users can enter a city name to retrieve information such as temperature, weather description, humidity, and wind speed.

The project demonstrates front-end web development, API integration, asynchronous JavaScript, responsive design, and version control using Git and GitHub.

## ✨ Features

- 🔍 **City Search:** Search for weather information by city name.
- 🌡️ **Current Temperature:** Display the current temperature in Celsius.
- ☁️ **Weather Description:** View the current weather condition.
- 💧 **Humidity:** Display the humidity percentage.
- 💨 **Wind Speed:** Show the current wind speed.
- ⚠️ **Error Handling:** Display an error message for invalid cities or failed requests.
- 📱 **Responsive Design:** Adapt the layout for different screen sizes.

*Note: Features depend on the current implementation. Add a 5-day forecast separately if it is not implemented yet.*

## ⚙️ Installation and Setup

Follow these steps to run the project locally.

### 1. Clone the repository
```
git clone https://github.com/juhiparwa-1507/weather-dashboard.git
```

### 2. Open the project folder
```
cd weather-dashboard
```

### 3. Configure the API key

1. Create an account at [OpenWeatherMap](https://openweathermap.org/api).
2. Generate an API key.
3. Configure the key in `script.js` where the code expects `YOUR_API_KEY`.

**Security note:** A key embedded in browser-side JavaScript is visible to visitors. Do not commit a private or unrestricted API key to a public repository. For production, use a backend or another secure approach to protect credentials.

### 4. Run the application

Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.

## 🚀 Deployment

This project can be deployed using GitHub Pages.

1. Push the project files to the `main` branch.
2. Open the repository's **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Choose `main` and `/(root)`.
5. Save and wait for deployment.
